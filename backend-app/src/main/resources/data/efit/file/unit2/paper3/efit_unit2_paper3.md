### Vocabulary (Cấu trúc & Cụm từ đáng chú ý)

* **Verb Synonyms (Đồng nghĩa)**: Các từ này được ghép cặp trong bài tập để chỉ cùng một hành động:
    * **turn on** -> **switch on** (bật)
    * **turn off** -> **switch off** (tắt)
    * **plug (into)** -> **put (into)** (cắm vào)
    * **unplug** -> **disconnect** (rút/ngắt kết nối)
    * **insert** -> **put (into)** (chèn vào)
    * **press** -> **push** (nhấn)
* **Noun Synonyms (Đồng nghĩa)**:
    * **cable** -> **connector** (dây cáp -> đầu nối)
    * **power socket** -> **electricity socket** (ổ cắm điện)
